## 방향

완제품이 공장에서 출하되고 창고에 입고된 뒤 판매 채널로 이동할 때, Applicell이 다음 질문에 답할 수 있어야 한다.

- 이 제품은 Applicell이 승인한 정품인가?
- 어느 생산 LOT, 어느 공장, 어느 출하 건에서 나온 제품인가?
- 완제품과 외부 케이스가 정상적으로 매칭되어 있는가?
- 창고·유통·소비자 단계에서 위조품, 재포장, 비정상 유통을 확인할 수 있는가?

---

## 작업 목록

### 1. 완제품·케이스 일련번호로 정품 확인

화장품 **완제품**과 외부 **케이스**에 고유 일련번호를 부여해 정품 확인이 가능하게 한다.

#### 목적

- 소비자·유통사·창고가 제품의 정품 여부를 확인할 수 있게 한다.
- 완제품과 케이스가 정상 매칭된 상태인지 확인한다.
- 위조품, 재포장, 비정상 유통, 중복 인증을 탐지할 수 있게 한다.
- 생산 LOT, 공장 출하, 창고 입고, 판매 채널까지 추적 가능한 기반을 만든다.

#### 검토할 방식

| 방식 | 설명 | 비고 |
|------|------|------|
| 제품 단위 일련번호 | 개별 완제품마다 고유 번호 부여 | 가장 정밀하지만 관리 비용 높음 |
| 케이스 단위 일련번호 | 외부 패키지마다 고유 번호 부여 | 소비자 정품 확인에 적합 |
| 제품 + 케이스 매칭 | 제품 번호와 케이스 번호를 1:1로 연결 | 재포장·바꿔치기 탐지 가능 |
| QR / 바코드 | 스캔으로 정품 확인 페이지 연결 | 구현·운영이 쉬움 |
| 봉인 라벨 | 개봉 시 훼손되는 라벨 사용 | 재포장 방지에 도움 |

#### 확인 질문

| 질문 | 메모 |
|------|------|
| 일련번호를 **제품**, **케이스**, **박스**, **팔레트** 중 어디까지 붙일 것인가? | |
| 제품 번호와 케이스 번호를 **같게** 할 것인가, **따로 만들고 매칭**할 것인가? | |
| 소비자가 직접 스캔하는 **정품 확인 페이지**가 필요한가? | |
| 한 번호가 여러 번 조회되면 경고를 띄울 것인가? | |
| 조회 시간, 국가, 대략적 위치, 채널 정보를 기록할 것인가? | |
| 중국 판매 시 위챗 미니프로그램 또는 플랫폼 내부 QR 흐름이 필요한가? | |
| 공장에서 번호를 붙이는가, Applicell 또는 포장 업체가 붙이는가? | |
| 일련번호 데이터는 기존 ERP/NetSuite와 연결해야 하는가? | |

#### 시스템 반영 후보

- 제품/케이스 일련번호 발급 화면
- 일련번호 업로드 또는 대량 생성 기능
- 제품 번호 ↔ 케이스 번호 매칭 테이블
- 생산 LOT, 물량, B 출하, C 입고와 일련번호 연결
- 창고 입고 시 스캔 검증
- 소비자용 정품 확인 페이지
- 중복 조회·비정상 조회 알림

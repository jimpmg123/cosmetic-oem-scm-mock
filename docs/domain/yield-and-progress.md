# 수율 · E2E · 달성도

## 수율 (단 하나의 의미)

**A Admin이 B에 보낸 발송 기준(grant) 대비, C가 실제 세어 확인한 입고량.**

- B가 “이만큼 만들었다”고 **주장**하는 숫자가 아님
- **C 입고(검증)** ÷ **A 발송 기준(grant)**
- 묶음·기간 **마감 후**에만 표시

```
수율 = receivedAtCTotal ÷ grantQty × 100
```

예: grant 1,100, C 입고 1,000 → **90.91%**

---

## E2E (수율 아님)

**End-to-End** — A **목표** 대비 C 입고가 끝까지 얼마나 채워졌는지.

```
E2E = receivedAtCTotal ÷ targetQty × 100   (마감 후)
```

라벨에는 **「E2E」만** 쓰고 「수율」을 붙이지 않음.

---

## 달성도 (수율 아님)

진행 중 묶음에서 “지금까지 얼마나 왔나”.

| 종류 | 식 |
|------|-----|
| 전체 (C입고) | C입고 ÷ 목표 |
| 전체 (B주장 생산) | 생산 ÷ 목표 |
| 기간 | 기간 내 생산 또는 입고 ÷ 지시 y |

---

## 로스 여유 (수율 아님)

A 통지 출하·BOM 산출 시 grant를 잡기 위한 **여유 %**.

---

## 비교

| | 분모 | 분자 | 시점 |
|---|------|------|------|
| **수율** | A 발송(grant) | **C 입고** | 마감 |
| **E2E** | A 목표 | C 입고 | 마감 |
| **달성도** | A 목표 | C입고 또는 B생산 | 진행 중 |

# B — 생산 캘린더 · 주간 그래프 · 일별 입력

**역할:** B Admin, B Staff  
**예정 경로:** `/operations/production-calendar`  
**목적:** **조회 전용** — 일별 일지에서 쌓인 데이터를 **캘린더 히트맵·주간 그래프**로 한눈에 보기.

**입력은 별도 창:** [b-daily-production-log.md](./b-daily-production-log.md) (생산·불량·원재료·QC·비고·첨부).

---

## 1. 페이지 레이아웃 (위 → 아래)

```
┌─────────────────────────────────────────────────────────┐
│ 페이지 헤더 + 묶음/SKU 필터 + 기간 선택                    │
├─────────────────────────────────────────────────────────┤
│ [접기] A 지시 카드 (이번 주 directive + comment)          │  ← Notion형 collapsible
├─────────────────────────────────────────────────────────┤
│ [접기] 이번 주 일별 생산 그래프                            │  ← Notion형 collapsible
├─────────────────────────────────────────────────────────┤
│ 월간 캘린더 (히트맵 셀)                                    │
├─────────────────────────────────────────────────────────┤
│ 요약 + CTA: [오늘 일지 작성] → /daily-log                   │  ← 입력은 일지 창에서
└─────────────────────────────────────────────────────────┘
```

## 2. 페이지 헤더

| 요소 | 내용 |
|------|------|
| 제목 | 생산 기록 |
| 설명 | 일별 생산 수량 입력 및 추이 확인 |
| 필터 — 자재 묶음 | select · **“전체 SKU 통합”** 옵션 |
| 필터 — 월 | month picker (캘린더·그래프·입력 동기) |
| (B Admin) | `검토 대기 N건` 링크 |

**다건 묶음:** 묶음 변경 시 캘린더·그래프·입력 패널 **전부 같은 bundleId** 로 리로드.

## 3. 섹션: A 지시 (Collapsible)

**Notion 동작:** 제목 행 클릭 → 본문 접힘/펼침. 접힌 상태에서는 **제목만** 표시 (그래프·지시 본문 숨김).

| UI | 내용 |
|----|------|
| 제목 (접힌 때도 표시) | `A 생산·출하 지시` + 뱃지 `2건 active` |
| 펼침 — 카드 목록 | 마감일 · 목표 y · 달성률 mini bar |
| 펼침 — **Comment** | A가 쓴 전문 (명절·블프·수요 변동) — 읽기 전용, 연한 배경 |
| 액션 | `전체 지시 보기` → directives 읽기 전용 |

기본 상태: **펼침** (첫 방문) / 사용자 접기 상태는 `localStorage` 저장 (선택).

## 4. 섹션: 이번 주 일별 생산 그래프 (Collapsible)

### 제목 행 (접기 타겟)

- 텍스트: `이번 주 생산` · 부제: `6/2 – 6/8` · (접힌 때) 합계 `1,240개`만 표시

### 펼침 — 차트

| 항목 | 스펙 |
|------|------|
| 차트 타입 | **세로 막대** (bar) — X: 월~일 7칸, Y: 생산 개수 |
| 데이터 | 선택 묶음(들)의 `DailyProductionEntry` 합계, **현재 주** |
| 보조선 | (선택) 해당 주 Directive `targetQty` / 7 일할 |
| 툴팁 | 날짜 · qty · scrap · 묶음명(SKU 통합 시) |
| 빈 날 | 0 — 막대 없음 또는 연한 회색 |

### 접힌 상태

- 그래프 영역 **완전 숨김** (height 0, aria-hidden)
- 제목 행 + 주간 합계 숫자만 유지

### 그래프 ↔ 입력 연동

- 하단 **일별 입력** 저장 시 막대 **즉시 갱신** (클라이언트 state, mock store).
- 주 변경(월 picker) 시 X축 라벨·데이터 재계산.

---

## 5. 섹션: 월간 캘린더 (히트맵)

### 그리드

| 항목 | 스펙 |
|------|------|
| 레이아웃 | 7열(일~토) × 5~6행, **월 뷰** |
| 셀 내용 | 날짜 숫자 + **당일 생산 qty** (tabular-nums) |
| 색상 — **그라데이션 히트맵** | qty에 따라 배경색 보간 |

### 색상 규칙 (확정안)

| 조건 | 배경색 | 의미 |
|------|--------|------|
| 0 또는 미입력 | `#f4f4f5` (neutral) | 생산 없음 |
| 낮은 qty | `#dcfce7` | 연한 연두 (light green) |
| 중간 | `#86efac` → `#16a34a` | 중간 녹색 |
| 높은 qty | `#7f1d1d` | 어두운 버건디 (dark burgundy) |

**보간:** 해당 **월·선택 묶음** 내 min~max qty 로 linear interpolate.  
전체 0이면 전 셀 neutral.

**접근성:** 색만이 아닌 **숫자 라벨** 필수; (선택) 패턴 또는 legend “적음 ← → 많음”.

### 인터랙션

| 동작 | 결과 |
|------|------|
| 셀 클릭 | 하단 입력 패널 **해당 일** 포커스, qty 필드 focus |
| 호버 | 툴팁: 날짜 · qty · scrap · note |
| 오늘 | ring border 강조 |

### 헤더

- `‹` `›` 월 이동 · “오늘” 버튼
- 월 합계: `이번 달 합계: 12,400`

## 6. 섹션: 주간 요약 + 일지 CTA (입력 없음)

| UI | 설명 |
|----|------|
| 이번 주 7일 미니 테이블 | 날짜 · 생산 · 불량 · 일지 상태(✓/—) · `편집` 링크 |
| `오늘 일지 작성` | primary → `/operations/daily-log?date=today` |
| 셀 클릭 | `/daily-log?date=…&bundleId=…` |

**데이터 소스:** [b-daily-production-log.md](./b-daily-production-log.md)의 `DailyProductionLog`.

**갱신:** 일지 제출 후 이 페이지로 돌아오면 그래프·히트맵 자동 반영.

## 10. 구현 메모 (개발자용)

- Collapsible: `@radix-ui/react-collapsible` 또는 shadcn `Collapsible` — **제목 행 + chevron**, `localStorage` key `b-prod-chart-collapsed`.
- 차트: recharts `BarChart` 또는 lightweight SVG.
- 히트맵: CSS `background-color` with computed HSL/RGB from normalized qty.
- 상태: `MockStore`에 `dailyProduction: { bundleId, date, qty, scrap, note }[]` 추가.

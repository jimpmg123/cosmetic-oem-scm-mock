## 5. 공동 KPI 정의 (숫자 싸움 방지)

| KPI | 정의 | A 노출 | B 노출 |
|-----|------|--------|--------|
| 묶음 진행 | `producedTotal / targetQty` | A2,A3b,A1 | B1,B2 바 |
| 지시 진행 | `producedInWindow / directive.y` (또는 shipped) | A3b,A1,A6 | B1,B2 — **metric 뱃지 동일** |
| B↔C | `received − shipped` (출하 건·묶음 합) | A6 | B1,B5 |
| E2E | `receivedAtCTotal / targetQty` | A6 | B1 read (Admin) |
| Material | `receivedAtCTotal / theoreticalQty` | A6 | Admin only |
| Transit gap | `A_shipped − B_confirmedReceipt` | A3b 이송 | B7 |
| 가용 생산 | `produced − defect − qcSample` | v1.1 A10 | v1.1 B3 tooltip |

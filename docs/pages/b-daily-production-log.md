# B — 일별 생산 일지 (Daily Production Log)

**역할:** B Staff (입력), B Admin (검토·수정)  
**예정 경로:** `/operations/daily-log` · 이력 `/operations/daily-log/history`  
**목적:** A가 정한 **자재 묶음·사용 기간** 동안, B가 **매일** 현장 실적을 한 창에서 제출.

**연관:** 추이·히트맵은 [b-production-calendar.md](./b-production-calendar.md) · A 지시는 [a-period-directives.md](./a-period-directives.md).

## 5. 입력 폼 (핵심)

### 5.1 수량 블록 (2열 grid, 큰 숫자 입력)

| 필드 | label (i18n 키 예) | 타입 | 필수 | 검증 |
|------|-------------------|------|------|------|
| `producedQty` | 오늘 생산 수량 | number ≥0 | ✓ | 정수 |
| `defectQty` | 오늘 불량 수량 | number ≥0 | ✓ | ≤ 생산+α 경고 |
| `qcSampleQty` | 오늘 QC 샘플 수량 | number ≥0 | **선택** (v1 기본 0) | 워크숍: [WORKSHOP-2026-06-03.md](./WORKSHOP-2026-06-03.md) |

**QC 정책 (PO 확정):**

- `producedQty`에 **QC 샘플 포함하지 않음** (별도 필드).
- **출하 상한:** `누적 shipped ≤ 누적 (produced − defect)` — **qcSample 제외**.
- **QC율 (확정):** `ΣqcSample / (Σproduced + ΣqcSample)` — **전체에서 샘플 비중**. UI: QC 누적 N + QC율 %.

**보조 표시 (저장 전):**

- 양품(출하 가용) ≈ `producedQty - defectQty` (QC 별도)
- **QC 오늘 / 누적 QC / QC율** 작은 카드
- 묶음·지시 진행은 **입고** 축 (B1과 동일, A 달성 기준) — 생산·출하는 보조

### 5.2 오늘 사용 원재료

**v1 (mock):** 요약 + 펼치기

| UI | 설명 |
|----|------|
| 토글 | `원재료 상세 입력` |
| 테이블 행 | 원료명(select 또는 text) · 사용량 · 단위(L/kg/ea) · LOT(optional) |
| `+ 행 추가` | A 출하 BOM 라인 프리필 (mock: 3행 고정) |
| 합계 행 | (선택) 생산 가능 수량 대비 % — v2 |

**v2:** 묶음 출하 `materialLines` 와 1:1 매칭, 미입력 시 경고.

| 필드 | 타입 |
|------|------|
| materialItemId / name | select |
| consumedQty | number |
| unit | read-only from master |
| lot | text |

### 5.3 비고

| 필드 | 타입 |
|------|------|
| `note` | textarea, 4~6줄 · placeholder: 라인 이슈, 교대, 설비 |

| UI | 스펙 |
|----|------|

## 8. 캘린더 페이지와 역할 분담

| 창 | 역할 |
|----|------|
| **일별 일지 (본 문서)** | **입력·첨부·원재료·QC** — “오늘 무엇을 했나” |
| [생산 캘린더](./b-production-calendar.md) | **조회** — 히트맵·주간 막대·접이 그래프·A 지시 |

**연동:**

- 캘린더 셀 클릭 → `/daily-log?date=YYYY-MM-DD&bundleId=`
- 캘린더 히트맵 색은 **`producedQty` 기준** (불량은 별도 작은 dot 또는 툴팁)

# A — 기간 지시 실적 분석 (Directive Period Analytics)

**역할:** Super Admin (A) **전용** — B Staff/C, B Admin 기본 메뉴에 **노출 안 함**  
**예정 경로:** `/operations/directive-analytics` · 묶음·지시에서 deep link `?directiveId=`  
**목적:** A가 발행한 **각 Period Directive(기간 케이스)** 를 하나의 단위로, 그 **기간 안**의 **생산 · 출하 · 입고** 누적을 보고 그래프로 확인.

**데이터 원천:** B2 생산 · B5 출하 · C3 입고 → 기간 창(`issuedAt`~`dueDate` 또는 지시별 window)으로 집계.

---

## 1. 배경·정책 (PO 확정)

| 항목 | 결정 |
|------|------|
| **지시 달성 기본축** | **입고 (`received`)** — 생산·출하는 참고 |
| **지시 met/missed** | **기간 내 C 입고 합 `receivedInWindow` ≥ y** |
| **생산** | B 일지 `producedQty` 합 — **달성 판정 보조**, 그래프 1계열 |
| **갱신** | B 저장 → 생산·출하 즉시 반영 · C 입고 저장 → 입고 계열 반영 |

## 4. 케이스 카드 (선택된 Directive 1건)

| 필드 | 소스 |
|------|------|
| 지시 번호 · 묶음 · SKU | directive |
| 목표 y | `targetQty` |
| comment | 전문 (펼치기) |
| C출하 요구 | checkbox 표시 |
| **기간 내 생산** | Σ `DailyProductionLog.producedQty` in window |
| **기간 내 출하** | Σ `Shipment.qty` in window |
| **기간 내 입고** | Σ `Receiving.receivedQty` in window (C) |
| **달성률 (주)** | `receivedInWindow / y` |
| 상태 | met / in_progress / missed (자동) |

## 5. 그래프

### 5.1 기본

| 항목 | 스펙 |
|------|------|
| 타입 | **누적 line** 또는 **일별 grouped bar** (토글) |
| X축 | 지시 window 내 **일** (또는 주) |
| Y축 | 개수 |
| 시리즈 | **생산** (연두) · **출하** (파랑) · **입고** (보라) — 3계열 동시 |
| 목표선 | horizontal **y** (지시 목표) |
| 툴팁 | 해당 일 생산/출하/입고 + **누적** |

### 5.2 인터랙션

| 동작 | 결과 |
|------|------|
| 범례 클릭 | 시리즈 on/off |
| 막대/점 클릭 | 하단 테이블 해당 **일** 하이라이트 |
| 접기 (Notion형) | 제목 + KPI 3숫자만 유지 |

### 5.3 QC (정책 연계)

- 별도 시리즈 **「QC 샘플」** (점선 또는 얇은 막대) — **생산 막대와 분리**
- 생산 누적에는 QC **미포함** (B2에서 `produced`와 `qcSample` 분리 입력)
- 툴팁: `QC 누적 N · QC율 = QC/(생산+QC)%`
